    Use your cookies

    Private, follower-only, members-only and age-restricted videos need a signed-in account. Export the cookies from a browser where you're signed in and add them here.

    1. Install a cookie exporter: Get cookies.txt LOCALLY for Chrome / Edge, or for Firefox.
    2. Open the site (for example instagram.com) and make sure you're signed in.
    3. Click the extension, choose Export, then add the file below.

    Cookies stay in this browser and are sent only with your own requests. The server uses them for that one lookup or download, then deletes them. They give access to your account, so only add them to a Grabbit you trust, or use a second account. YouTube tip: export from a private window, then close it, so the cookies keep working.
